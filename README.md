# AI 研究室 V2.5 / AI Research Lab V2.5

獨立 iPhone PWA 專案；與必勝羅盤 V40、舊版 AI-WarRoom-iOS 完全隔離。

## 專案狀態
- 工程交付 Repository 已建立；應用程式原始碼尚未交付。
- 本 Repository 目前為 **Public**。不得提交 API 金鑰、Token、使用者對話、私密附件或其他秘密。
- 目標：GPT 與 Meta AI 雙方研究、可選 Gemini 判官、1–7 回合辯論、證據追溯、離線資料保存、匯入匯出。
- 若任何供應商缺乏合法可用的 API，必須顯示 MANUAL MODE；不可偽造 AI 回覆。
- 工程師不必具備 GitHub 權限，可提供 ZIP 或完整檔案集合交中央總指揮驗收。
- 只有通過 build、測試與正式部署檢查後才能宣告 PASS。

請先閱讀 [工程交付命令](docs/ENGINEER_HANDOFF.md) 與 [驗收矩陣](docs/ACCEPTANCE.md)。

## 交付邊界
工程師負責寫程式、自測、修正；中央總指揮負責收件、審查、授權範圍內的 GitHub 整合、部署與驗收。沒有測試證據一律 NOT TESTED。禁止覆蓋任何既有正常服務。
